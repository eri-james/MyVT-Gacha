MyVT Gacha - Portrait Downloader

Download all 319 VTuber portrait images from hololist.net and package as ZIP

How to Use

  1. First, open hololist.net in a new tab and wait for the page to fully load (this gives your browser a Cloudflare clearance cookie).
  2. Come back to this page and paste your characters.json data below (or load it from a URL).
  3. Click "Start Download" — the tool will fetch each image and build a ZIP.
  4. When done, click "Download ZIP" to save the file. Extract into your repo's data/portraits/ folder.
  5. If images fail, try the "CORS Proxy" mode or run the Python script instead.
